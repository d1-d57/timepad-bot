Бот для организаторов фестиваля «Фрактальная Одиссея» (Matema-фест, 23 мая 2026). Как только на Timepad покупают или возвращают билет, в Telegram приходит сообщение вида «Новая продажа: 2 × 800 ₽ … Всего: …». Бот нужен, чтобы следить за продажами, не открывая админку Timepad.

Весь сервис — `app.py` на Flask (233 строки) и `render.yaml` для хостинга Render. Точка `POST /timepad-webhook` проверяет подпись вебхука HMAC-SHA1, разбирает билеты заказа, делит их на оплаченные и возвраты и шлёт сообщение; `GET /` отвечает Render, что сервис жив. Пять секретов — токен и чат Telegram, секрет вебхука, токен API и id события Timepad — задаются переменными окружения.

Счётчик живёт только в памяти процесса. Историю заказов собирались подгружать из API при старте, но Timepad отвечал 403, поэтому стартовые числа вписаны руками из админки: 78 билетов по 800 ₽ и 3 по 1000 ₽. Возврат старого билета, которого бот не видел, всё равно уменьшает счёт по его цене.

Бот сделан в мае 2026 к фестивалю; единственный коммит — 15.05.2026, он добавил ручные стартовые числа и починил возвраты старых билетов. Описание модуля до сих пор обещает загрузку истории из API, хотя код этого не делает. Слабое место видно по коду: после перезапуска или засыпания бесплатного сервиса Render счётчик возвращается к 78 + 3, и продажи после запуска из суммы пропадают.

Сюда идти, если снова продаются билеты через Timepad и нужны уведомления: код короткий и переносится как есть, но стартовые числа и id события придётся заменить. Связи: сайт фестиваля `matema-fest` с виджетом TimePad и другие репозитории фестиваля; похожие уведомления о заявках теперь умеет `ankety`.

# Timepad → Telegram bot

Бот для уведомлений в Telegram о продажах билетов на Timepad-фестивале.
Деплой на Render через render.yaml. Все секреты — через переменные окружения.
